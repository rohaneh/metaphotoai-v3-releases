# MetaPhotoAI

**AI-Powered Metadata Generation for Stock Photography**

MetaPhotoAI is a professional desktop application that uses artificial intelligence to automatically generate high-quality metadata (titles, descriptions, keywords, and categories) for your stock photos. Built specifically for stock photographers, it streamlines your workflow and helps you get your images to market faster.

## 📥 Download

### Latest Release

Download the latest version for your platform from the [Releases](https://github.com/rohaneh/metaphotoai-v3-releases/releases/latest) page.

**Supported Platforms:**
- 🍎 **macOS** 10.13+ (High Sierra and later) - Universal binary (Intel & Apple Silicon)
- 🪟 **Windows** 10/11 (64-bit)
- 🐧 **Linux** (64-bit AppImage)

### Installation

**macOS:**
1. Download `MetaPhotoAI-[version].dmg`
2. Open the DMG file
3. Drag MetaPhotoAI to your Applications folder
4. On first launch, right-click the app and select "Open" (to bypass Gatekeeper)

**Windows:**
1. Download `MetaPhotoAI-[version].exe`
2. Run the installer
3. Follow the installation wizard
4. Launch from Start Menu or Desktop shortcut

**Linux:**
1. Download `MetaPhotoAI-[version].AppImage`
2. Make it executable: `chmod +x MetaPhotoAI-[version].AppImage`
3. Run: `./MetaPhotoAI-[version].AppImage`

## ✨ Key Features

### Intelligent Metadata Generation
- **AI-Powered Titles** - Descriptive, SEO-friendly titles that capture your image
- **Detailed Descriptions** - Comprehensive descriptions with customizable length
- **Smart Keywords** - Relevant, searchable keywords automatically generated
- **Platform-Specific Categories** - Adobe Stock, Shutterstock, Dreamstime categories

### Batch Processing
- Process hundreds of images at once
- Background processing - continue working while metadata generates
- Resume interrupted batches
- Track progress with detailed status updates

### Multi-Platform Export
- **EXIF Writing** - Embed metadata directly into image files
- **CSV Export** - Customizable templates for bulk uploads
- **FTP/SFTP Upload** - Direct upload to stock agencies
- Platform-specific metadata formatting

### Professional Workflow
- Folder-based organization
- Per-folder settings overrides
- Editorial vs. commercial content handling
- Custom metadata templates
- Color tagging for organization
- Advanced filtering and search

### Flexible Settings
- Customizable title/description length
- Keyword count control
- Compound keyword handling
- Blacklist words and phrases
- Location and date integration
- Custom prompts for specialized content

## 🚀 Getting Started

1. **Sign In** - Create a free account or sign in with your existing credentials
2. **Add Folders** - Point MetaPhotoAI to your image library
3. **Select Images** - Choose images to process
4. **Generate Metadata** - Let AI create professional metadata
5. **Review & Edit** - Fine-tune as needed
6. **Export** - Write to EXIF, export CSV, or upload via FTP
